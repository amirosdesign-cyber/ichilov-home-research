# חיבור השאלונים המקוצרים ל-Google Forms

הסקריפט `GoogleFormsSetup.gs` יוצר שני Google Forms מתוך שאלות המחקר המדויקות:
- מטופלים: 7 שאלות בחירה + שאלה פתוחה אחת.
- בני משפחה: 7 שאלות בחירה + שאלה פתוחה אחת.
- לפני שמונה שאלות התוכן יש סעיף הסכמה מנהלי חובה (לכן Google Forms יציג 9 פריטים בטופס).

## ביצוע

1. פתחו את [טבלת המחקר](https://docs.google.com/spreadsheets/d/1KYVYhWHubT-V_BgmT-pjAImbbh4jIxd8AT7zSo2a4qg/edit).
2. **תוספים / Extensions → Apps Script** (באותו פרויקט שבו נמצא `Code.gs` של בדיקת הדמה).
3. לחצו **+ → Script** ליצירת קובץ חדש בשם `GoogleFormsSetup.gs` (לא למחוק את `Code.gs`).
4. העתיקו את הקוד מקובץ GitHub `integration/GoogleFormsSetup.gs` לקובץ החדש בעורך ושמרו.
5. בחרו `createShortResearchForms` ולחצו **Run / הפעלה**. אשרו את ההרשאות רק אם הן מתאימות לפרויקט.
6. ביומן הביצוע יופיעו שני הקישורים **RESPONDENT_URL** (למשתתפים) ו-**EDITOR_URL** (לצוות). *אל תשלחו למשתתפים את קישורי העריכה.*
7. בדקו שאין בגדרות Google Forms איסוף כתובות דוא"ל או דרישת התחברות; הקוד מגדיר ביטול איסוף כתובות אך מומלץ לבדוק גם בממשק.
8. בצעו תשובת דמה אחת לכל טופס, וודאו שבטבלת המחקר נוצרות שתי לשוניות תשובות חדשות ושהתקבל מייל התראה ל-`amiros.design@gmail.com`.
9. שלחו בשיחה את שני **RESPONDENT_URL** כדי שנעדכן את כרטיסיות השאלון המקוצר באתר GitHub Pages. ריאיונות העומק לא ישתנו.

## חשוב

- הטפסים נפתחים תחת החשבון שהריץ את הסקריפט ומועברים לתיקיית **Ichilov HOME — Research**.
- הטפסים מקושרים לטבלת המחקר הקיימת; Google יוסיף *לשוניות תגובות חדשות*. ארבע לשוניות המחקר שכבר נוצרו לא יימחקו.
- הודעות המייל כוללות שם הטופס וקישור לטבלה בלבד, לא את תוכן התשובה.
- אין להפעיל איסוף תשובות אמיתיות לפני בדיקת אישורי המחקר, תוכן ההסכמה, שמירת נתונים והרשאות.
- פעולה זו דורשת הרשאות ליצירת Forms, העברת קבצים ב-Drive, כתיבה ב-Sheets ושליחת מיילים, שיכולות להיות רחבות יותר מגישה לתיקיית המחקר בלבד.
